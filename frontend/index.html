Routiner Khichuri: BRACU Routine Generator

Routiner Khichuri helps BRAC University students generate clash-free class routines quickly. Instead of manually checking every section in USIS, you can pick your course codes, choose preferred faculties, avoid specific faculties, apply day and time constraints, and generate valid combinations in seconds. The routine builder also includes seat status visibility so you can filter out filled sections and focus on options that are still practical to register.

Key Features

The app checks class-time overlap, lab overlap, and exam-time overlap before suggesting a routine. You can set preferred class days, ignore specific time slots, and prioritize fewer class days or lower daily load. Faculty preferences are course-specific, so you can keep one faculty for a course while avoiding another in a different course. When some faculty names are not announced yet, sections are grouped under TBA so you can still include or exclude them intentionally.

How It Works

The backend fetches the course catalog, normalizes section schedules, and searches for combinations that satisfy your constraints. Valid schedules are ranked using metrics such as total active days, idle gap penalty, and daily span quality. Only exam-clash-free routines are returned. This means the results are usable for actual registration planning, not just rough suggestions.
